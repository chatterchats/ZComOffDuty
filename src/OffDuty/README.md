# Off Duty v0.1.0 — Operator Fatigue and Recovery for Star Wars: Zero Company

> **In development.** This build doesn't change gameplay yet. It's here so the
> package, mod managers and release pipeline can be tested.

Tired of sending the same four operators on every mission? With Off Duty,
operators **get tired from back-to-back deployments** and **recover while
they're off duty**, so the rest of your company gets a chance to shine.

## What's planned

- **Fatigue builds with every deployment.** Long missions and going down
  add more.
- **Rest brings them back.** Each cycle an operator sits out, they recover.
- **Tired operators are still yours to send.** Tired means a small penalty
  next mission. Exhausted means a bigger one, plus a longer recovery
  afterwards. You can always push someone through; the game never locks you
  out.
- **Story missions are safe.** Operators the story needs can always deploy.
- **No surprises.** Squad select shows the exact penalty before you commit.
- **Separate from injuries.** The game's injury system is left as it is.

## What you need

- Star Wars: Zero Company
- UE4SS for Star Wars Zero Company (from Nexus Mods)

## Installing

### With a mod manager

Install the downloaded ZIP with Zero Mod Manager or Zero Company Mod Command
and make sure Off Duty is switched on.

### By hand

1. Close the game.
2. Open the ZIP and drag the **OffDuty** folder into your game's UE4SS mods
   folder:
   `SWZeroCompany/Binaries/Win64/ue4ss/Mods/`
3. Start the game.

## Uninstalling

Switch Off Duty off or remove it in your mod manager, or delete the
**OffDuty** folder.
